01 sobre

Oi, eu sou o Thalys.

Sou desenvolvedor em Natal/RN. Comecei em 2022 com a formação de Desenvolvimento Web da Trybe e hoje curso Tecnologia em Sistemas para Internet no IFRN, com conclusão prevista para 2027.1.

Meu trabalho mais completo até aqui foi um ano de residência no EmbarcaTech, construindo em equipe a API de um sistema que monitora equipes em obras sem internet, onde nenhum registro pode se perder. O projeto passou por banca, foi apresentado à Softex e virou artigo publicado.

Trabalho principalmente no backend, com Node.js, TypeScript, Python e PostgreSQL, e levo o projeto até a ponta quando preciso, com React, Next.js ou Flutter. Escrevo testes, documento a API e gosto de deixar o caminho fácil para quem vem depois.

Fora do código: jogos, filmes, animes e Muay Thai.

Residência EmbarcaTech · 2025–2026 · equipe

API de monitoramento de equipes em campo

Equipes em obras remotas registram presença com crachás RFID, muitas vezes sem internet. Nenhum registro pode se perder.

  • API em Node.js e Express que recebe as leituras dos dispositivos e grava no PostgreSQL.
  • Consultas paginadas e processamento em lote para registros que chegam após períodos offline.
  • 32 testes automatizados (Jest + Supertest) e documentação interativa com Swagger.
  • Firmware do ESP32 com armazenamento local e sincronização.

Trybe · projeto de formação em backend

Trybe Futebol Clube

API de um campeonato de futebol: login, partidas com placar ao vivo e classificação geral, de mandantes e de visitantes, calculada a partir dos jogos encerrados. Desenvolvi o backend para a interface React fornecida pela Trybe.
